# 修复数据流链路方案

## 问题根因
NATS Bridge 存在订阅冲突，导致无法消费 NATS 消息，Celery 队列为空，分析任务未执行。

## 修复步骤

### 1. 重启 NATS Bridge 容器
- 停止并重新启动 `tx-news-nats-bridge-1` 容器
- 清理可能的订阅冲突

### 2. 重启 Worker 容器
- 停止并重新启动 `tx-news-worker-1` 容器
- 确保 Celery worker 正常连接到 Redis

### 3. 检查 NATS JetStream 状态
- 验证 NATS stream 和 consumer 状态
- 确认消息可以正常消费

### 4. 验证数据流恢复
- 检查 Celery 队列是否有新任务
- 验证 analyses 和 signals 表是否有新数据
- 测试前端是否能看到更新

## 预期效果
- NATS Bridge 正常消费消息
- Celery 队列有任务
- 分析任务正常执行
- 前端能看到数据更新
